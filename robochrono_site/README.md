# RoboChrono Project Page

Static project page for **RoboChrono: A REAL ROBOT BENCHMARK FORSTREAMING TASK UNDERSTANDING**.

## Local preview

Open `index.html` in a browser from this folder. The current page references videos directly from `../data/`.

## GitHub Pages deployment

1. Create a GitHub repository for the project.
2. Upload the contents of this folder, then add the required video assets or replace the video paths with hosted Hugging Face URLs.
3. In the repository settings, enable GitHub Pages from the repository root.
4. Replace the placeholder Paper and GitHub links in `index.html` before release.

For a public GitHub Pages repository, compressed video assets are recommended before uploading the full dataset.
