# RoboChrono Project Page

Static project page for **RoboChrono: A Real-Robot Benchmark for Streaming Task Understanding**.

## Local preview

Open `index.html` in a browser from this folder. The page only references repository-relative files under `assets/`, so it works unchanged after deployment to GitHub Pages.

## GitHub Pages deployment

1. Create a GitHub repository for the project.
2. Upload the contents of this folder, including `assets/images/` and `assets/videos/`.
3. In the repository settings, enable GitHub Pages from the repository root.
4. Replace the placeholder Paper and GitHub links in `index.html` before release.

The four Stack Cubes previews are pre-rendered at 2× speed, compressed for web delivery, and have no absolute local paths.
